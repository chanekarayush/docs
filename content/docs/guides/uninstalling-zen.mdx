---
title: Uninstalling Zen Browser
description: How to uninstall Zen Browser Desktop App on Linux, macOS and Windows
---

This guide helps you uninstall Zen Browser from your device.

Uninstalling the app and deleting your data are two separate steps. Your profile (bookmarks, history, passwords, tabs, extensions and settings) is stored outside the app, so removing the app alone leaves it behind. If you reinstall later, Zen picks that profile up again.

<Callout type="warn">
Deleting your profile is permanent. If you might want your data later, back it up first using [Managing Firefox Profiles](/guides/manage-profiles). To find your exact profile folder, open `about:profiles` in Zen.
</Callout>

## Linux

### Flatpak

1. Close Zen completely.

2. Check whether Zen is installed for your user or for the whole system. The last column shows `user` or `system`.

```bash
   flatpak list --app --columns=application,installation | grep zen
```

3. Uninstall Zen.

   To remove the app **and** its data:

```bash
   flatpak uninstall --delete-data app.zen_browser.zen
```

   To remove the app but **keep** your data:

```bash
   flatpak uninstall app.zen_browser.zen
```

   If Flatpak asks which installation to use, or the install was user-only, add `--user` (or `--system`) after `uninstall`. You can also click **Uninstall** in GNOME Software or KDE Discover.

4. If you uninstalled without `--delete-data` and now want your data gone too, delete the app's data folder. This includes your profile:

```bash
   rm -rf ~/.var/app/app.zen_browser.zen
```

   `rm` deletes files, `-r` includes everything inside the folder, and `-f` skips confirmation prompts.

5. Optional: remove runtimes that no other Flatpak app uses.

```bash
   flatpak uninstall --unused
```

6. If a Zen icon still shows in your app menu, log out and back in to refresh the menu cache.

### Tarball install script

The tarball script installs Zen into your home folder. There is no uninstall script, so remove the files yourself.

1. Close Zen completely.

2. Remove the app, its launcher and its menu entry:

```bash
   rm -rf ~/.tarball-installations/zen
   rm -f ~/.local/bin/zen
   rm -f ~/.local/share/applications/zen.desktop
```

   If you also installed Twilight, remove it too:

```bash
   rm -rf ~/.tarball-installations/zen-twilight
```

3. Optional: delete your profile and cache (this deletes your data). Your profile is usually in `~/.zen`. If `about:profiles` showed a different path, such as `~/.config/zen`, delete that folder instead.

```bash
   rm -rf ~/.zen
   rm -rf ~/.cache/zen
```

## macOS

1. Quit Zen (Cmd+Q).

2. Open Finder > Applications, drag **Zen** to the Trash, and empty the Trash. Or, from Terminal:

```bash
   rm -rf /Applications/Zen.app
```

3. Optional: delete your profile and cache (this deletes your data). Dragging the app to the Trash does not remove them.

```bash
   rm -rf "$HOME/Library/Application Support/zen"
   rm -rf "$HOME/Library/Caches/Zen"
```

   If you prefer Finder, use Go > Go to Folder and paste the same paths. An app cleaner such as AppCleaner can also find leftovers, but check the folders above afterwards.

## Windows

1. Close Zen, including any background process in Task Manager.

2. Uninstall the app: open Settings > Apps > Installed apps, find **Zen Browser**, click the three dots and choose **Uninstall**. If you installed it with winget, run this in PowerShell or Terminal instead:

```powershell
   winget uninstall Zen-Team.Zen-Browser
```

3. Optional: delete your profile and cache (this deletes your data). In PowerShell:

```powershell
   Remove-Item -Recurse -Force "$env:LOCALAPPDATA\Zen"
   Remove-Item -Recurse -Force "$env:APPDATA\zen"
```

   `-Recurse` includes everything inside the folder and `-Force` skips confirmation. If a command says the folder doesn't exist, that's fine. You can also press Win+R, paste `%LocalAppData%\Zen` or `%AppData%\zen`, and delete the folder by hand.

4. Restart if Windows reports that a file is in use.
